# Nix

Generally it's recommended to follow the [Nixpkgs code conventions].

[Nixpkgs code conventions]:https://github.com/NixOS/nixpkgs/blob/master/CONTRIBUTING.md#code-conventions

Particularly:

* Names of files and directories should be in lowercase, with dashes between words.
* Use `lowerCamelCase` for variable names, not `UpperCamelCase`.
